# infoLLC! Website

Professional responsive jewelry website for **infoLLC!**.

## Included
- Elegant jewelry homepage
- Rings, necklaces, bracelets, and earrings
- Product filters and sample pricing
- Interactive bag counter
- About section and newsletter form
- Responsive mobile navigation
- GitHub Pages ready

## Files
- `index.html`
- `styles.css`
- `script.js`

## Publish
Upload all files to the root of your GitHub repository, then go to:

**Settings → Pages → Deploy from a branch → main / root → Save**

Product names and prices are sample content. Photography is loaded from Unsplash.
